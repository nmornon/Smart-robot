Description détaillée

Gestion de l'interface et lecture des fichiers de ville.

  • Ce module permet de transformer un fichier texte en structure de ville, d'afficher les résultats à l'écran et de traduire un chemin en ordres compréhensibles pour le robot (AV, TG, TD).

Crée une ville à partir d'un fichier texte.

  • Le fichier doit suivre le format :
  1. Largeur, 2. Case départ + Orientation, 3. Passages (X-Y) ou cases obligatoires (X).

    nom_fichierChemin vers le fichier .txt
