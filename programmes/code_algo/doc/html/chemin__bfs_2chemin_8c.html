Detailed Description

Gestion des trajets et calcul d'itinéraires optimaux dans la ville.

  • Ce fichier contient les algorithmes pour créer des chemins, calculer des plus courts chemins (BFS) et optimiser l'ordre de passage par plusieurs points obligatoires.
