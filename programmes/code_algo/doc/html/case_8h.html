Description détaillée

Gestion des cases individuelles (sommets du graphe).

Auteur
Groupe 2-6
Date
07/12/2025

Ce .h définit la structure d'une case, qui est l'élément atomique de la ville. Une case connait ses voisins (adjacences) et ses propriétés (si elle est une étape obligatoire ou non).
