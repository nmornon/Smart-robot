Description détaillée

Gestion de la strucutre de données représentante le plus court chemin du robot.

Auteur
Groupe 2-6
Date
13/12/2025

Ce .h défini la structure d'un chemin qui sera la structure qui permet de représenter de manière cohérente le chemin le plus court que le robot va parcourir
