Detailed Description

Gestion de la ville (le graphe complet).

Author
Groupe 2-6
Date
07/12/2025

Ce .h gère la structure globale de la ville, qui contient l'ensemble des cases. Il fait le lien entre la grille (largeur) et le graphe (connexions). Il stocke également les informations de départ du robot.
