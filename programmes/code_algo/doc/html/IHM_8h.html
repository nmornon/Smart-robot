◆ IHM_chargerVilleDepuisFichier()

V_Ville * IHM_chargerVilleDepuisFichier ( const char *  nom_fichier)

Crée une ville à partir d'un fichier texte.

Paramètres
nom_fichierChemin vers le fichier de description (.txt).
Renvoie
Pointeur vers la ville créée, ou NULL si le fichier est invalide.

Crée une ville à partir d'un fichier texte.

  • Le fichier doit suivre le format :
  1. Largeur, 2. Case départ + Orientation, 3. Passages (X-Y) ou cases obligatoires (X).
  • Paramètres
    nom_fichierChemin vers le fichier .txt
    Renvoie
    Un pointeur vers la ville créée, ou NULL en cas d'erreur.
