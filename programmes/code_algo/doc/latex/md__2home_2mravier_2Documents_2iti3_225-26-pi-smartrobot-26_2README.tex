\hypertarget{md__2home_2mravier_2Documents_2iti3_225-26-pi-smartrobot-26_2README_autotoc_md3}{}\doxysection{\texorpdfstring{Objectif du Projet}{Objectif du Projet}}\label{md__2home_2mravier_2Documents_2iti3_225-26-pi-smartrobot-26_2README_autotoc_md3}
L\textquotesingle{}objectif principal de ce projet est la conception, la réalisation et la programmation d\textquotesingle{}un {\bfseries{robot mobile}} capable de naviguer de manière autonome dans un environnement simulé (une ville composée de rues modélisées par des lignes noires).

Le robot doit \+:
\begin{DoxyEnumerate}
\item {\bfseries{Partir}} d\textquotesingle{}un point initial (pastille verte).
\item {\bfseries{Passer}} par tous les points de passage obligatoires (pastilles bleues).
\item {\bfseries{Revenir}} à son point de départ.
\end{DoxyEnumerate}

Le critère de performance est le {\bfseries{temps le plus court}} pour réaliser l\textquotesingle{}intégralité du trajet.

\hypertarget{md__2home_2mravier_2Documents_2iti3_225-26-pi-smartrobot-26_2README_autotoc_md5}{}\doxysection{\texorpdfstring{Modélisation et Description de la Ville}{Modélisation et Description de la Ville}}\label{md__2home_2mravier_2Documents_2iti3_225-26-pi-smartrobot-26_2README_autotoc_md5}
La ville est modélisée par une grille de cases formant un carré.

Le problème est décrit à l\textquotesingle{}aide d\textquotesingle{}un {\bfseries{flux texte structuré}} qui définit\+:
\begin{DoxyItemize}
\item La largeur \$l\$ de la ville en nombre de cases
\item La case de départ et son orientation initiale (N, E, S, O)
\item Les passages entre les cases (ex\+: {\ttfamily 1-\/2})
\item Les numéros des cases contenant les points de passage obligatoires (pastilles bleues)
\end{DoxyItemize}\hypertarget{md__2home_2mravier_2Documents_2iti3_225-26-pi-smartrobot-26_2README_autotoc_md6}{}\doxysection{\texorpdfstring{Architecture Logicielle et Contrôle}{Architecture Logicielle et Contrôle}}\label{md__2home_2mravier_2Documents_2iti3_225-26-pi-smartrobot-26_2README_autotoc_md6}
L\textquotesingle{}exécution du projet repose sur une architecture en deux programmes communicants, orchestrés par un script {\ttfamily bash}.

\hypertarget{md__2home_2mravier_2Documents_2iti3_225-26-pi-smartrobot-26_2README_autotoc_md9}{}\doxysection{\texorpdfstring{Composants Matériels (\+Partie Électronique)}{Composants Matériels (Partie Électronique)}}\label{md__2home_2mravier_2Documents_2iti3_225-26-pi-smartrobot-26_2README_autotoc_md9}
Le robot est équipé des composants suivants\+:
\begin{DoxyItemize}
\item {\bfseries{Contrôle/\+Alimentation \+:}} Châssis, Contrôleur L293D, Raspberry Pi, Interrupteur on/off.
\item {\bfseries{Déplacement \+:}} 2 moteurs + roues + supports.
\item {\bfseries{Capteurs \+:}} 1 Capteur couleur, 3 Capteurs détecteurs de ligne.
\item {\bfseries{Interface \+:}} Buzzers, LED, Écran LCD (pour afficher les manœuvres en continu et les couleurs détectées en émettant un bip).
\item {\bfseries{Batteries \+:}} 1 batterie USB-\/C pour la Raspberry Pi 4, 2 batteries NIMH 3,7V + support.
\end{DoxyItemize}
